# Sidebar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Launcher buttons in a full-width bottom row, emoji icons for Spaces, a resizable and hideable sidebar with an Arc-style slide-out, and agent activity moved to Settings.

**Architecture:** Every rule is a pure type in `SingularityCore` with tests (launcher list, one-emoji rule, width clamp, slide-out rules); the app only wires them to views. The sidebar stays one `SidebarView`, moved off screen with an offset when hidden. A launcher's command lives in memory in `AppState.pendingCommands` and is typed into the new tab's shell once.

**Tech Stack:** Swift, SwiftUI, AppKit, SwiftTerm; Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-13-sidebar-design.md`

## Global Constraints

- No new dependency. Settings change only through `AppState.updateSettings`.
- A launcher's command is never written to `space.json` and is typed at most once per tab.
- Sidebar width: default 270, minimum 220, maximum 480.
- No test makes a window key, runs `claude`/`codex`, or touches the owner's real config files.
- No SwiftUI `.help()` on chrome in the title-bar strip.

## Review Focus

1. `settings.json` with a broken `launchers` entry (wrong types, no command): the other launchers and every other setting survive. Test in Task 1.
2. A launcher clicked in a Space that has projects but the folder has none: the picker asks, and the choice starts the launcher, not a plain terminal. Test in Task 4.
3. A terminal restarted with Return after its launcher's program and shell ended: nothing is typed again. Test in Task 4.
4. An icon field given text, several emoji, or a flag / family emoji (many scalars, one grapheme): one emoji or nothing. Test in Task 1.
5. Sidebar hidden while the welcome flow covers the window or a sheet is up: no slide-out, window buttons visible. Rules test in Task 1; wiring in Task 6.
