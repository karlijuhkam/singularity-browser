# Apps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An artifact folder with a `wrangler.jsonc` gets a sandboxed local Cloudflare-style Worker, a D1-shaped SQLite database, and outside requests to hosts the owner allowed, with keys Singularity holds.

**Architecture:** The artifact server keeps serving files; a request under an app folder that has no file goes to one Bun process per app (`app-host.ts`, under the plugin sandbox profile), which speaks JSON lines with the app over stdin/stdout. The Worker's `fetch` is sent back over the same wire and made by the app with `URLSession` after a host check and key substitution. Every rule is a pure function in `SingularityCore/Apps/`, tested; the app target holds processes, `URLSession`, the keychain and the UI.

**Tech Stack:** Swift 6 / SwiftUI / AppKit, FlyingFox, bundled Bun 1.4.4 (`bun:sqlite`), `sandbox-exec`, Security.framework. No new dependency.

**Spec:** `docs/superpowers/specs/2026-11-13-apps-design.md` (approved by the owner 2026-11-14, with the keychain exception).

## Global Constraints

- No new dependency. Verify D1's client API, wrangler's migrations table and config keys against Cloudflare's documentation before writing the wrapper; do not rely on memory.
- Boring, readable Swift; comment the non-obvious AppKit/WebKit/sandbox parts (the owner reads TypeScript more fluently).
- Never touch the real keychain, the real `~/Singularity`, or a real outside host in a test. Tests use `MemoryAppKeyStore`, temp roots (`TestAppState.makeRoot()`), and a fixture server on 127.0.0.1.
- App tests: nested in `AppTests`, start `MainRunLoopGuard` first, never make a window key.
- Key values and placeholders are never logged.
- Outside an app folder the artifact server's behaviour must not change (GET/HEAD, files only).
- Builds and tests go through `scripts/` (they set `DEVELOPER_DIR`); one Swift build at a time in this worktree.
- Limits (the spec left them to the builder): request and response bodies 8 MB; a Worker request 30 s; an outside request 30 s; Worker start 20 s; idle stop after 600 s; `worker.log` cut to its last 200 lines when it passes 256 KB; a wire line at most 16 MB.

## Review Focus

1. A Worker that never answers (infinite loop): the request must end with 504 after 30 s and the process must be killed, not leave the tab spinning.
2. A request arriving while the Worker restarts after a file change: it must wait for the new process, not fail or reach the old code.
3. A redirect from an allowed host to one that isn't: must fail with an error naming the host, and the key must not travel.
4. Two apps where one's folder name is a prefix of the other's (`firma`, `firma2`): requests, keys, hosts and data must not cross.
5. A key value that contains regex or JSON metacharacters, or is a substring of ordinary text: substitution and log scrubbing must be exact string replacement and must not corrupt the body.

## The wire (both sides build against this)

One JSON object per line. Headers are `[[name, value], …]`. Bodies are base64 or `null`.

App → Worker (stdin):

| Message | Fields |
|---|---|
| `start` | `keys: {NAME: string}` (real value or placeholder), `dataFolder: string`, `appFolder: string` |
| `request` | `id`, `method`, `url` (prefix already stripped), `headers`, `body` |
| `fetchResult` | `id`, then either `status`, `statusText`, `headers`, `body`, `url` or `error: string` |
| `stop` | none; the host waits for `waitUntil` promises (at most 30 s) and exits 0 |

Worker → App (stdout):

| Message | Fields |
|---|---|
| `ready` | none; sent after config, migrations and the Worker's import succeeded |
| `failed` | `message: string`; then exit 1 |
| `response` | `id`, `status`, `headers`, `body` |
| `fetch` | `id`, `method`, `url`, `headers`, `body` |
| `log` | `level: "info" \| "error"`, `text` |
| `envRead` | `name`; once per name the Worker read from `env` that is not defined |

End of stdin = exit at once.

```swift
public enum AppHostRules {
    /// The host an outside request is for, lowercased, or the reason it is refused.
    /// https any host; http only for localhost, 127.0.0.1, [::1]. No userinfo. Other schemes refused.
    public static func target(of url: String) -> Result<String, AppFetchRefusal>
    public static func isValidHost(_ text: String) -> Bool      // for the panel's "add a host"
}
public struct AppFetchRefusal: Error, Equatable, Sendable { public var message: String }

/// One running Worker's view of its hosts. Pure; the caller holds it on one actor.
public struct AppHostGate: Sendable {
    public enum Decision: Equatable { case allow, refuse, ask, joinWaiting }
    public init(allowed: Set<String>)
    public mutating func decide(_ host: String) -> Decision     // ask marks the host as waiting
    public mutating func answered(_ host: String, allowed: Bool)
    public mutating func setAllowed(_ hosts: Set<String>)       // the panel changed them; un-denies an added host
    public var deniedThisRun: [String] { get }                  // sorted, for the panel
}

public protocol AppKeyStore: Sendable {
    func value(space: UUID, app: String, name: String) -> String?
    func set(_ value: String, space: UUID, app: String, name: String) throws
    func delete(space: UUID, app: String, name: String)
    func deleteAll(space: UUID, app: String?)                   // nil app = the whole Space
}
public final class MemoryAppKeyStore: AppKeyStore
public final class FileAppKeyStore: AppKeyStore                 // <root>/app-keys.json, 0600, atomic; for SINGULARITY_HOME copies

public struct AppKeyMaterial: Sendable { public var name, host, value, placeholder: String; public var readable: Bool }
public enum AppKeySubstitution {
    public static func makePlaceholder() -> String              // "sgkey_" + 32 hex
    /// What `start` hands the Worker: the value for readable keys, the placeholder otherwise.
    public static func environment(_ keys: [AppKeyMaterial]) -> [String: String]
    /// Placeholders → values in the URL, header values and a UTF-8 body, only for keys whose host == host.
    public static func outgoing(url: String, headers: [(String, String)], body: Data?, host: String, keys: [AppKeyMaterial])
        -> (url: String, headers: [(String, String)], body: Data?)
    /// Values → placeholders in header values and a UTF-8 body (non-readable keys only).
    public static func incoming(headers: [(String, String)], body: Data?, keys: [AppKeyMaterial]) -> (headers: [(String, String)], body: Data?)
    /// Every key value (readable or not) → "[key NAME]"; placeholders too.
    public static func scrubLog(_ line: String, keys: [AppKeyMaterial]) -> String
    public static func isValidName(_ name: String) -> Bool      // ^[A-Za-z_][A-Za-z0-9_]*$, at most 64
}
```

public struct AppHTTPRequest: Sendable { public var method, url: String; public var headers: [(String, String)]; public var body: Data? }
public struct AppHTTPResponse: Sendable { public var status: Int; public var headers: [(String, String)]; public var body: Data }
public enum AppWorkerError: Error, Equatable, Sendable { case failedToStart(String), timedOut, exited, tooLarge }

public final class AppWorkerProcess: @unchecked Sendable {
    public init(appFolder: URL, dataFolder: URL, runtime: URL, hostFolder: URL, keys: [String: String])
    /// Makes outside requests for the Worker (host check, keys and URLSession live in the app target).
    public var onFetch: (@Sendable (AppHTTPRequest) async -> Result<AppHTTPResponse, AppFetchRefusal>)?
    public var onLog: (@Sendable (_ level: String, _ text: String) -> Void)?
    public var onEnvRead: (@Sendable (String) -> Void)?
    public var onExit: (@Sendable () -> Void)?

    public func handle(_ request: AppHTTPRequest) async throws -> AppHTTPResponse   // 30 s, then timedOut and the process is killed
    public func stop()                          // `stop` message, SIGKILL after 35 s
    public func terminateNow()                  // SIGKILL
    public var isRunning: Bool { get }
}
public final class AppLog: @unchecked Sendable {   // <dataFolder>/worker.log
    public init(file: URL, scrub: @escaping @Sendable (String) -> String)
    public func append(level: String, text: String)
    public func lastLines(_ count: Int) -> [String]
}
